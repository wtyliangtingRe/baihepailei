# 百合排雷投稿

这个仓库只接收公开的待核实线索，不包含网站源码、正式研究数据或数据库。提交 Issue 不会自动改变作品资料或评级。

在 Issues → New issue 选择“作品资料补充与纠错”或“推荐收录新作品”。请附作品名、Work ID（如已收录）和可核验来源；不知道的信息可以留空。

可以在表单的图片栏附 PNG、JPG、JPEG、WebP 截图。每张须小于 GitHub 的 10 MB 上限，建议压缩到 2 MB 以内，并说明版本、话数/页码和出处。不要提交视频、SVG、压缩包或文档。

公开仓库中的文字和图片可能被任何人查看。请勿提交私人联系方式、未经允许公开的聊天、未公开材料或无权公开的图片。涉及剧透时请标明。图片由 GitHub 托管，网站不自动下载或镜像。

投稿将由维护者核实身份与来源后处理；重复、无关或垃圾投稿可被关闭。请查看 [投稿规范](CONTRIBUTING.md)。
