# 投稿规范

- 一条 Issue 聚焦一部作品或一个明确的问题。同名作品、改编版、不同卷或路线请写清楚。
- 简介只需一两句话，优先提供作品前提和识别信息。
- 译名、作者、制作机构和日期请附来源；不要把猜测写成确定事实。
- 图片请去除个人信息，并说明原作位置；禁止垃圾信息、广告、人身攻击及侵犯他人隐私的内容。
- 提交内容始终是待核实材料，关闭 Issue 或添加标签不会自动更新正式数据库。
- 禁止要求维护者运行附件、下载程序、提供密码或使用投稿链接登录账户。

图片栏的扩展名限制只约束该栏。GitHub 的正文和评论仍可能允许其他附件，因此本规范还需要人工执行；它不是全仓库附件防火墙。
