# Detail layout summary

This branch refines frontend detail page structure.

## Changes

- Entity names remain inline links in basic information.
- Work summary is rendered before retained materials.
- Retained materials remain a dedicated place for screenshots and other evidence.
- A lightweight comment block placeholder is available on detail pages.
- A full registered-user comment system is documented as future work.
- Image-text callout shape is documented for migrated decorative blocks.

## Not included

- No automatic plot summary generation.
- No full comment write system yet.
- No evidence import fix.
