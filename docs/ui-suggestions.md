# UI suggestions

Current frontend direction:

- Keep dark mode as the default atmosphere, but provide a light mode for long reading.
- Use cards and section spacing to break long rule pages into readable chunks.
- Prefer inline internal links for creators, organizations, works, and terms instead of wiki-style relation boxes.
- Keep creator and organization pages lightweight: related works first, retained materials later.
- Keep work pages richer: basic info, summary, retained materials, comments, and feedback.
- Convert old XWiki warning and image-text templates into frontend callout blocks when possible.
- Avoid showing raw legacy syntax on frontend pages whenever a lightweight rendering fallback can make it readable.

Future improvements:

- Add a table of contents for long rule pages.
- Add collapsible rank sections for very long rules.
- Add clearer mobile spacing for large heading pages.
- Add a real comments collection after the placeholder UI is accepted.
