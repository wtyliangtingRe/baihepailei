# Frontend search page

This document describes the first public search page.

## Route

```text
/search
```

The page reads the generated local file:

```text
public/search-index.json
```

This file is generated by:

```powershell
pnpm export:lite-search -- --url "http://localhost:3000" --include-drafts
```

The generated index is ignored by Git and should not be committed yet.

## Local test flow

1. Start Payload and Next.js:

```powershell
cd "D:\0GitHubtest\Baihepailei\_repo"

docker compose up -d postgres
pnpm dev
```

2. Generate the search index in another PowerShell:

```powershell
cd "D:\0GitHubtest\Baihepailei\_repo"

$env:PAYLOAD_SEED_EMAIL="your-admin-email@example.com"
$env:PAYLOAD_SEED_PASSWORD="your-admin-password"

pnpm export:lite-search -- --url "http://localhost:3000" --include-drafts
```

3. Open:

```text
http://localhost:3000/search
```

## Current behavior

The search page supports:

- keyword search
- collection filters
- title highlighting
- simple weighted scoring
- empty state when `public/search-index.json` does not exist
